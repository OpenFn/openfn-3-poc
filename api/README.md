# The API spec has moved

The Lightning API spec now lives in
[OpenFn/lightning-api-spec](https://github.com/OpenFn/lightning-api-spec).
Clone it beside this repo (`../lightning-api-spec`).

- The pages that were here, `api/<page>.md`, are now `spec/<page>.md` there.
- `api/register.md` and `api/misfits.md` are now in its `notes/`.
